# Home Bakery Order Tracker

A local order manager for a home bakery. Built with Python's standard library and SQLite.

## Start the app

1. Install Python 3 if it is not already on your computer.
2. In this folder, run `python app.py`.
3. Open http://127.0.0.1:8000 in your browser.

The app creates `bakery.db` locally when it starts. Customer/order data files are intentionally excluded from this public repository. Keep real customer data private and do not commit the database or Instagram message files.

See [README.html](README.html) for the full feature and usage guide.
